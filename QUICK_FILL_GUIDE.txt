CARA KERJA
================================================================================

1. Buka setiap file di editor
2. Gunakan Ctrl+F untuk cari text di "CARI:"
3. Ganti dengan text Anda sesuai "GANTI:"
4. Save
5. Ulangi untuk semua file

ATAU gunakan PowerShell (hati-hati, test dulu):

# Contoh replace URL repo
$content = Get-Content README.md -Raw
$content = $content -replace '\[ISI - URL repository GitHub Anda\]', 'https://github.com/yourname/araktrace.git'
$content | Set-Content README.md
